## Permission received

The project owner shared a written email response from Mel at Pangram Pangram. The operative
permission was:

> You can use the fonts for your non-commercial public student-club website.

This is explicit permission to use Neue Machina for the described BlueNode website while it
remains a non-commercial public student-club project.

## Scope to preserve

- Permitted project: the BlueNode public student-club website.
- Permitted context: non-commercial use.
- Public website use is included by the vendor's written response.
- This record does not extend the grant to unrelated projects, client work, paid products,
  merchandise, resale, sublicensing, or commercial campaigns.
- If the website's purpose or operator changes materially, re-confirm the licence with Pangram
  Pangram before continuing to use the font.

This is an internal project record, not legal advice and not a replacement for the original
email. The project owner should retain the complete email in their own archive.

## File-handling rules

- Local Neue Machina desktop files and the downloaded EULA are stored under
  `reference-materials/noomo-neue-machina-personal-use.local/`.
- The `.local` directory is already excluded by `.gitignore` and must remain untracked.
- Do not commit or redistribute the original OTF files in the public repository.
- Do not place the desktop OTF files directly in a publicly downloadable source folder.
- The public prototype uses a WOFF2 conversion of the single approved display weight, which is
  the vendor-recommended delivery format for websites and remains scoped to this non-commercial
  public student-club website under the written permission above.
- Production web file: `pp-neue-machina-inktrap-regular.woff2`.

## Approved design role

- Large English display: PP Neue Machina Regular, weight `400`, normal.
- Korean display, body, navigation, labels, and metadata: Pretendard.
- Neue Machina is not used for long body copy.

The vendor also mentioned a 40% student discount and the commercial Font Starter Pack. Those
options are not required for the present non-commercial BlueNode site, but should be reviewed
if the project later becomes commercial.
